# Dorothy Ang

This is the code behind my personal website [workwithdorothy.com](https://workwithdorothy.com).

## What's on the site

I set it up the way I'd introduce myself if we met in person. First, what I can help with. Then my experience, how I like to work, and a look at my home office.

After that, a bit of life outside work: my learning map from Obsidian, books I love, places I've been, and the piano I'm slowly getting back into. There's also a calling card you can flip and a letter to future clients. It's the part of me that doesn't fit on a CV.

## How it's built

It's a simple, editorial-style site written in plain HTML, CSS and JavaScript. The homepage is `index.html` and my portfolio is `portfolio/index.html`. Whenever I update this repo, Cloudflare Pages publishes the changes automatically.

## A note on AI

I coded this site myself but agent helped me with a few other things like link preview settings and how the site behaves when you rotate your phone & across other devices. The idea, the words, the design direction and everything else coded here are mine.

I'm also vibe coding a Notion-style workspace for a future client. It's still in progress and isn't part of the public site.
