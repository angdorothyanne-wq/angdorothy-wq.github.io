# Dorothy Ang

This is the code behind my personal website [workwithdorothy.com](https://workwithdorothy.com).

## What's on the site

I set it up the way I'd introduce myself if we met in person. First, what I can help you with. Then my experience, how I like to work, and a look at my home office.

After that, a bit of life outside work: my learning map from Obsidian, books I love, places I've been, and the piano I'm slowly getting back into. There's also a calling card you can flip and a letter to future clients. It's the part of me that doesn't fit on a CV.

## How it's built

It's a simple, editorial-style site written in plain HTML, CSS and JavaScript. The homepage is `index.html` and my portfolio is `portfolio/index.html`. Every time I update this repo, Cloudflare Pages publishes the changes automatically.

## A note on AI

Claude helped me with a few fiddly bits, like link preview settings and how the site behaves when you rotate your phone. The idea, the words, the design direction and everything else are mine.

I'm also vibe coding a Notion-style workspace behind the scenes for my future client. It's still in progress and isn't part of the public site.
